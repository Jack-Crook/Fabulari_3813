Fabulari — Phase 1 storyboards

Low-fidelity wireframes, mobile-first with a desktop breakpoint shown per screen. Grey striped boxes = image/illustration placeholders. These define the layout the Phase 1 prototype UI must reflect for each permission level.
User flow:
00-login → 01-user-dashboard → 02-group-channels → 03-chat-room

Group Admin sees 01–03 plus 04-group-admin (settings, members, banned list, channel-request approvals, deletion request).

Super Admin lands on 05-super-admin instead of 01 (pending requests, banned accounts, audit log) and does not use 02–04.
Screens
00 — Login / Register 01 — User dashboard (My Groups / Discover / Requests) 02 — Group → channel list 03 — Chat room (presence, text + image messages) 04 — Group Admin panel 05 — Super Admin console
