Responsive rule: mobile collapses sections into an accordion; desktop uses a persistent nav rail (Requests / Banned Accounts / Audit Log) with the panel content beside it.
Spec notes reflected: Super Admin only actions requests (group create/delete, user ban) — never creates/edits/bans directly, and can't self-approve; bans shown here are permanent (hard delete, email locked forever) — no "unban" control exists; audit log is filterable by type and sorted by date, and shows all activity system-wide.
Flow: only entry point reachable by the Super Admin role; separate from the group/channel/chat screens a regular user or group admin sees.
